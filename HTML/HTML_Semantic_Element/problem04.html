Important Technology Terms

RAM
Random Access Memory used by a computer to temporarily store information needed by running applications.
SSD
Solid State Drive, a storage device that provides fast data access and quick system performance.
Refresh Rate
The number of times a display updates its image per second, commonly measured in Hz.
